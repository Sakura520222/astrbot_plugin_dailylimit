# 限额回归测试

在仓库根目录运行，Python 标准库即可，无需安装 AstrBot、Redis 或 WebUI 依赖：

```bash
python -m unittest discover -s tests -v
```

测试直接加载真实核心模块，验证启动配置、重载删除/替换/清空规则、无效替换不残留、专属限额、共享与独立计数、默认回退、优先级用户、豁免和跳过规则。时段测试验证实际添加/禁用命令、重叠时段的原始索引、缺少启用字段的兼容性，以及 Limiter 既有跨夜和显式索引行为。

`support.py` 从 `main.py` 提取真实构造函数和方法，仅移除框架装饰器并替换 Star 基类；Web 保存测试提取真实配置更新和保存重载方法。配置持久化、AstrBot 事件与消息、Redis、日志及无关管理模块使用替身，时间固定。这些是隔离回归测试，不是完整 AstrBot/HTTP/Redis 集成测试；Redis 并发、TTL 到期、指令注册和防刷启用流程不在验证范围内。

时段通过真实管理命令创建，避免将既有时段文本解析或 TimePeriodManager 跨夜问题混入本次回归门槛。未改变共享群里的用户专属阈值仍使用群共享计数的现有策略。
