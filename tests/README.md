# 限额回归测试

在仓库根目录运行，Python 标准库即可，无需安装 AstrBot、Redis 或 WebUI 依赖：

```bash
python -m unittest discover -s tests -v
```

测试直接加载真实核心模块，验证启动配置、重载删除/替换/清空规则、无效替换不残留、专属限额、共享与独立计数、默认回退、优先级用户、豁免和跳过规则。时段测试运行真实添加/禁用/删除命令和 LLM 请求，覆盖跨午夜计数、配置重置时间前后的日期与 TTL、使用记录及统计、状态显示跳过禁用条目、旧索引计数迁移，以及删除/重排/修改限额后保持时段身份和用量。无法映射的旧索引必须拒绝请求并保留计数。并发测试暂停实际配置解析，检查读者只见完整旧规则或新规则、管理命令等待发布，以及发布后保留字典别名。

`support.py` 从 `main.py` 提取真实构造函数和方法，仅移除框架装饰器并替换 Star 基类；Web 保存测试运行真实 `_update_config` 入口及其预检、保存、重载和回滚方法，另覆盖保存失败后恢复原配置和运行期间 Redis 不可用时保留原时段。配置持久化、AstrBot 事件与消息、Redis、日志及无关管理模块使用替身，时钟可控。`redis_stub.py` 模拟绝对到期时间、重命名、扫描及事务；其 `eval` 只模拟仓库已知迁移脚本的语义，不执行 Lua。这些是隔离回归测试，不是完整 AstrBot/HTTP/Redis 集成测试；真实 Redis Lua 执行、跨进程并发、指令注册和防刷启用流程需要独立集成验证。

时段主要通过真实管理命令创建，Web 重排测试通过保存的时段文本重载。显式旧索引仍可调用，但已知时段会映射到稳定身份；测试不依赖身份哈希算法。未改变共享群里的用户专属阈值仍使用群共享计数的现有策略。

当前日历日和当前重置周期的旧计数迁移后，TTL 统一到下一次配置重置时间，不沿用旧午夜 TTL 或取旧期限最大值。已迁移但仍使用短期限的稳定计数也须在首次验证时修正。耗尽额度的测试在修正后不发送任何成功请求，验证午夜仍不能恢复额度，直到配置重置时刻才允许新请求。历史周期的迁移继续保留原到期时间；合并时保留较长期限或永久期限。Redis 替身保留旧迁移脚本识别，便于用同一测试运行修复前版本。

## Issue #21 回归

`test_issue21.py` 验证群组、用户及全部重置，缺失/无效参数、自定义重置周期、重复重置、Redis 断开，以及重置用户时保留同 ID 群组的共享计数。共享群组重置同时清理该群共享与个人日计数，保留其他群、私聊、其他周期和统计记录。

状态测试覆盖普通与豁免用户在共享模式、独立模式及私聊中的行为，群组/默认额度、优先用户和个人额度、当前时段、查询权限及自定义消息。查询不修改配额、配置和 Redis TTL；共享额度耗尽后，豁免用户仍可调用且不计数。

## AstrBot 解析器和真实 Redis

Linux 上可额外运行上游解析器、权限过滤器及真实 Redis 测试。准备一个 AstrBot 源码目录，并安装 Python `redis` 客户端及本机 `redis-server`：

```bash
python -m pip install 'redis>=4.5.0'
ASTRBOT_SOURCE=/path/to/AstrBot \
DAILYLIMIT_TEST_REDIS_SERVER=redis-server \
python -m unittest discover -s tests -v
```

也可安装 `redislite==6.2.912183`，使用其 `redislite.__redis_executable__` 指向的 Redis 二进制。测试只连接自己启动的临时实例：绑定本机随机 TCP 端口、关闭持久化，退出后清理进程及目录。不会读取或清理现有 Redis 服务。

`test_command_integration.py` 执行所选 AstrBot 源码中的真实 `CommandFilter` 和 `PermissionTypeFilter`，仅替换框架导入依赖；从插件实际装饰器读取命令名与权限，通过过滤器绑定参数后调用真实插件方法，覆盖空白分词、字符串 ID、缺失/无效参数，以及普通用户和豁免用户均无权重置的情况。真实 Redis 测试还核对所有键的序列化值和 TTL，确保查询及豁免调用不写数据，重置不会污染其他计数和统计。

未提供环境变量时，这些可选测试会跳过；显式配置后，源码加载或 Redis 启动失败会使测试失败。CI 在 AstrBot v4.10.0 和 v4.29.1 对应的固定源码提交上执行全部测试。此验证覆盖上游解析/权限算法及真实 Redis，不启动完整 AstrBot、平台适配器或实际指令注册流程。
